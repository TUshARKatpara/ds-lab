# Contributing

Thanks for your interest in contributing to this project.

## Good First Contributions

- Improve the README
- Add more example commands
- Add new website shortcuts
- Improve error handling
- Make features work better across different operating systems

## How To Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make a small, focused improvement.
4. Test the project locally.
5. Open a pull request with a clear description.

## Code Style

- Use clear function names.
- Keep features small and easy to understand.
- Do not commit passwords, API keys, or private files.
- Prefer environment variables for user-specific settings.

## Reporting Issues

When opening an issue, include:

- What you expected to happen
- What actually happened
- Your operating system
- Your Python version
- Any error message you saw
